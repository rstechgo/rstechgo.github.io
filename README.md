# RS Tech - Site Institucional

Site institucional responsivo para divulgação de serviços de criação de sites.

## Arquivos

- `index.html`
- `style.css`
- `script.js`
- `assets/logo-rs.png`

## Personalização obrigatória

Antes de publicar, altere no `index.html` e no `script.js`:

- `55SEUNUMERO` pelo seu WhatsApp com DDI + DDD + número.
- `(19) XXXXX-XXXX` pelo número exibido.
- `seuemail@exemplo.com` pelo seu e-mail.

## Rodar localmente

Abra a pasta no VS Code e use a extensão Live Server, ou apenas abra o `index.html` no navegador.

## Publicação

Pode ser publicado no GitHub Pages, Netlify ou Vercel.
